# Security

This is a demonstration on fictional data, but it is built to handle personal data carefully, and reports are
welcome.

- **Report a vulnerability** through GitHub's private vulnerability reporting (the repository's *Security* tab,
  then *Report a vulnerability*). Please do not open a public issue.
- **In scope:** any way to read another visitor's case or another person's records, to release a pack without an
  approval, to get personal data into telemetry or advisor payloads, or to get a visitor's API key out.
- **Never send real personal data** to the demo, including in a report.

The threat model is in [docs/threat-model.md](docs/threat-model.md).
